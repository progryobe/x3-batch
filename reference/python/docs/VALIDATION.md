`docs/screenshot.png` はLinuxオフスクリーン画面。Macのウィンドウ装飾・フォントは異なる。

## Macで最後に確認すること

- `bash Start.command` で起動し、Finderからフォルダをドロップする。
- 1 / 2 / 10の順序、サムネイル、ドラッグ並べ替え、Fit / Fillを確認する。
- 500枚の実画像を変換し、キャンセル後に同じ保存先へ再実行する。
- `bash scripts/build-macos.sh` の .app をFinderから起動する。
- `examples/calibration.xtch` をX3へコピーし、左右上下、4段階の濃淡、ページ送りを確認する。その後、実画像の500ページ版を確認する。
